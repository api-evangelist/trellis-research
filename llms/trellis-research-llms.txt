# Trellis Research

> Trellis (trellis.law) is an AI-powered state and federal court research and litigation analytics platform. It aggregates the most extensive U.S. trial court data available — State Trial, Federal, District, Appellate, Supreme Court, and Bankruptcy cases across all 50 states plus DC — and exposes it through Smart Search, a REST Data API (V2), and a remote MCP server for case, docket, document, ruling, verdict, judge, party, and expert research plus litigation analytics.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public documentation (the trellis.law site is behind bot protection). Values marked as behind the sales-gated reference are not reproduced.

## APIs

- [Trellis Trial Court Data API (features)](https://trellis.law/legal-data-api): Case, judge, document, and metadata search; record download; case/topic alerts; daily case updates.
- [Trellis API documentation](https://support.trellis.law/trellis-api): REST Data API V2 (May 2024) — federal + PACER integration. Endpoints: Search (Boolean/query, filter/sort over Cases, Documents, Rulings), Rulings, Judges, Usage (billing-cycle usage stats), Webhooks (manage refresh/alert notifications).

## MCP

- [Trellis Law MCP server](https://support.trellis.law/trellis-law-mcp-technical-documentation): Remote MCP at https://mcp.trellis.law/mcp, OAuth 2.0 (PKCE S256, dynamic client registration, scope `mcp`). Tool families: case research, documents, rulings, verdicts, judges, parties & experts, analytics, taxonomy.

## Authentication

- REST Data API: API key in the `Authorization` header, generated from Trellis account Settings; server-side only.
- MCP server: OAuth 2.0; no API keys exposed to the client.
